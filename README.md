## 1. Описание проекта

Данная программа предназначена для анализа данных по страхованию транспортных средств и прогнозирования вероятности страховой выплаты (CLAIM_PAID). Проект включает в себя полный цикл: от предобработки данных и поиска ассоциативных правил до обучения нейронных сетей и создания системы управления моделями.

## 2. Стек технологий
Язык: Python 3.13

Библиотеки: 
-scikit-learn (ML пайплайны, RandomForest, MLP)

-mlxtend (алгоритм FP-Growth для поиска закономерностей)

-pandas, numpy (обработка данных)

-joblib (сериализация моделей)

-sqlite3 (хранение данных)

## 3. Сбор данных
Реализован функционал сбора потоковых данных, хранилище сырых данных и расчет метапарметров. Также реализована система логирования и обработка ошибок на этапе сбора данных.

## 4. Анализ данных
Выполнена оценка и хранение показателей качества данных, выбраны 5 ассоциативных правил для проверки корректности данных, добвлены новые признаки: длительность страховки. 

## 5. Подготовка данных
Были обработаны пропуски в категориальных и числовых данных. 

## 6. Обучение модели
В проекте обучены две модели: RandomForest и нейронная сеть.

## 7. Валидация модели
В проекте реализован метод Hold-out валидация (разделение на обучающую и тестовую выборки с использованием stratify для сохранения баланса классов). Оценка производится по метрикам ROC-AUC, Precision, Recall, F1-score.

## 8. Обслуживание модели
Для использования моделей в реальных условиях применена сериализация через joblib.

## 9. Управление программой
Центральным узлом управления является класс ModelManager, поддерживающий следующие операции:

- метод predict() для получения прогнозов по новым данным.

- метод update() для автоматического переобучения модели на новых данных и обновления файла final_model.pkl.

- метод summary() для визуализации текущей структуры пайплайна и используемых параметров.

##10. Инструкция по развертыванию
Проект может быть запущен локально и через CI/CD pipeline.
Если запускать локально: 

- нужно установить зависимости: pip install -r requirements.txt

- запуск обучения модели: python run.py -mode update

- запуск инференса: python run.py -mode inference -file data/*.csv

- получение отчета: python run.py -mode summary

Если запускать через CI/CD,срабатывает автоматически при:

- pull в ветку main
- pull request в ветку main
- по расписанию (ежедневно в 00:00)

Алгоритм работы:
1. Устанавливается окружение;
2. Выполняется обучение;
3. Генерируется отчет;
4. Формируются артефакты: логи, обученная модель.
